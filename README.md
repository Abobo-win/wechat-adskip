# 微信小游戏去广告

跳过微信小游戏的激励视频广告。广告不播放，奖励直接到账。

**永久免费 · 开源 · 带设置开关**

---

## 这是什么

一个 iOS 越狱插件，让微信小游戏里的「看广告 30 秒得奖励」直接跳过。

以前小游戏的激励视频走原生 SDK，所以 hook ObjC 的老插件（老猫助手、GDDTHookByX、NoPublicAds……）都能拦。
后来微信改成了**运行时下载一个 1.58MB 的纯 JS 库（`WAGameAd.js`）在 JS 引擎里求值**——所有传统去广告插件**同时失效**了。

**不是插件坏了，是广告搬家了。**

本插件 hook 的是 JS 引擎的求值入口，在广告库执行**之前**改写源码字符串。只改内存，不动磁盘。

---

## 适用条件

| 项目 | 要求 |
|---|---|
| 系统 | iOS 15.0 – 16.6.1 |
| 越狱 | **Dopamine（rootless）** · 测试环境 iOS 15.6.1 / iPhone 13 Pro |
| 依赖 | `ellekit` · `preferenceloader` |
| 微信 | 8.0.72 测试通过 |

理论上 trollstore 之外的其他 rootless 越狱（palera1n rootless 等）也能用，但我没条件测。

## 安装

### 方式一：Sileo 源（推荐，能自动更新）

```
Sileo → 源 → 右上角 + → 添加：

https://Aboo-win.github.io/wechat-adskip/

→ 进「小游戏去广告」→ 安装
```

### 方式二：下载 deb 手动装

从 [Releases](../../releases) 下载 `.deb`，用 Sileo / Filza 打开安装。

---

## 使用

装完之后去：

```
系统设置 → 往下翻 → 「小游戏去广告」→ 打开开关
```

然后**重启微信**（后台划掉再打开）。

小游戏里点「看广告得奖励」→ 广告不播，奖励直接到账。

---

## 已知限制

- **部分小游戏拿不到奖励**：如果那个游戏的开奖由**服务端校验**，客户端补丁拿不到奖励。这不是插件的问题，是那个游戏的设计。
- **微信更新后可能失效**：微信改 `WAGameAd.js` 的结构就会失效。我踩坑的记录和自查方法都写在下面的「开发文档」里了。
- **只支持 iOS 15–16.6.1**：更高版本的越狱环境没测过。
